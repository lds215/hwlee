벡터

2026년 9월 9일(수)

0. 벡터를 사용하는 이유

  1. 자연 현상을 설명하기 편하기 때문.
  2. 자연 현상을 표현하고 해석하기 편하기 때문.

0.1 벡터의 사용처 : 물리학 및 운동학

  1. 힘, 속도, 가속도, 운동량(Momentum) 등 크기와 방향이 중요한 물리량을 표현하고 계산할 때
  2. 바람의 방향과 풍속, 비행기의 이동 경로 계산 등에 활용.

0.2 중요 관점

  1. 좌표
  2. 변환
  3. 곱:
    1. 스칼라곱: scalar product, dot product 또는 내적(inner product), 일반수학의 곱셈을 확장한 것이다.
    2. 벡터곱 : vector product, cross product, 외적(outer product), 가위곱
  4. 스칼라장, 벡터장: 여기서의 장은 영어로 field, 예로 운동장의 장과 같은 뜻이다.
    1. 물리량을 공간상의 지점에 할당한다.
    2. 참고 : 수학에서의 체(field)
      1. 원소와 4칙 연산을 포함하는 개념이다.
      2. 공간이라고도 부른다. 스칼라장 = 스칼라공간, 벡터장 = 벡터공간
  5. 미분과 적분
    1. (스칼라와 관련된) 그래디언트(기울기)
    2. (벡터와 관련된) divergence(발산), curl(회전) 을 설명하기 위해 미분연산자(del∇\nabla∇)를 도입하였다.
    3. (벡터와 관련된) 가우스정리, 그린정리, 스토크스 정리를 설명하기 위해 적분을 이용하였다.

1. 표기법 : 중요

수식에서 모든 문자는 이탤릭체가 기본이다.
예

  1. abc 123 : 수식이 아닐 때
  2. abc 123abc\ 123abc 123 : 수식일 때

관전 포인트

  1. 벡터
  2. 행렬
  3. 집합

곱셈

  1. 고등학교까지 배우는 일반 수학에서의 곱셈, aaa와 bbb의 곱하기 표현 : 3가지, 모두 같은 뜻이다.
    1. a×ba \times ba×b
    2. a⋅ba \cdot ba⋅b
    3. ababab
  2. 벡터에서의 곱하기 표현 : 3가지, 서로 다른 뜻이다.
    1. 내적 : a⃗⋅b⃗\vec{a} \cdot \vec{b}a⋅b : 벡터와 벡터의 곱
    2. 외적 : a⃗×b⃗\vec{a} \times \vec{b}a×b : 벡터와 벡터의 곱
    3. 스칼라와 벡터의 곱셈
      1. aF⃗a\vec{F}aF

1.1 벡터 표기

  1. a⃗,x⃗,v⃗\vec{a}, \vec{x}, \vec{v}a,x,v : 변수 위에 오른쪽 화살표를 그린다. 책과 필기체에서 사용, 주로 필기체에서 사용
    1. AB→\overrightarrow{AB}AB : 시점(AAA)과 종점(BBB) 표기
  2. a,x,v\mathbf{a, x, v}a,x,v : 볼드체(굵고 진하게 표시하는 글꼴), 책에서 사용
  3. 벡터는 기본적으로 소문자를 사용한다.
    1. 다만, 특별한 경우 대문자를 사용하는 경우도 있다.
    2. 예: 스칼라와 벡터
      1. F=maF = maF=ma : FFF와 aaa는 스칼라.
      2. F=ma\mathbf{F} = m\mathbf{a}F=ma : F\mathbf{F}F와 a\mathbf{a}a는 벡터이다.

참고

  1. 책에서는 볼드체와 화살표 둘다 사용한다.
    1. 책에서는 주로 볼드체를 사용한다. a\mathbf{a}a
    2. 그리고 일관성을 위해 해당 책에서는 둘 중 하나만을 사용한다.
  2. 손으로 쓰는 필기체에서는 화살표를 사용한다. a⃗\vec{a}a
    1. 볼드체는 손으로 쓴 후, 구별이 힘들다.

1.2 괄호 표기 : 수학에서는 3가지만을 사용한다.

종류

  1. 소괄호 : ( ) : 벡터의 원소 표기, a⃗=(1,2)\vec{a} = (1, 2)a=(1,2), a⃗\vec{a}a는 벡터.
  2. 중괄호 : { } : 집합에서 사용, A={1,2}A = \{1, 2\}A={1,2}, AAA는 집합
  3. 대괄호 : [ ] : 선형대수학, 즉 행렬에서 사용 B=[1234]B = \begin{bmatrix} 1& 2 \\ 3 & 4 \end{bmatrix}B=[13​24​], BBB는 행렬

1.2.1 괄호를 이용한 벡터 성분 표기

2가지가 있다.

  1. a⃗=(1,2)\vec{a} = (1, 2)a=(1,2) : 소괄호, 해당 벡터의 성분표기이다.
  2. a⃗=[1,2]\vec{a} = [1, 2]a=[1,2] : 대괄호, (선형대수학의) 행벡터를 표기한 것이다.

1.3 나머지 표기

  1. 기본적으로 벡터와 (벡터와 집합의)원소는 소문자로 표기 : (벡터)a⃗\vec{a}a와 (집합)A={b,c}A = \{b, c\}A={b,c}의 bbb와 ccc
    1. 벡터는 대문자도 자주 쓰인다. (벡터)A\mathbf{A}A : 대문자, 볼드체
  2. 기본적으로 행렬과 집합은 대문자 표기 : 행렬 AAA, 집합 BBB
  3. 수 체계 집합 : 칠판체(칠판에 쓰는 글꼴)
    1. N,Z,Q,R,C\mathbb{N, Z, Q, R, C}N,Z,Q,R,C : 자연수 집합, 정수 집합, 유리수 집합, 실수 집합, 복소수 집합
