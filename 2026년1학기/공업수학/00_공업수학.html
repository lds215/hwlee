1. 공학이란?

목적 : 자연세계를 연구하여 실세계에 적용하고자 하는 것이 목적이다.

graph LR; A["입력"] --> B["시스템"] --> C["출력"] AA["X"] --> BB["H"] --> CC["HX"]

1.1. 용어

  1. 도함수 = 원함수를 미분한 결과로 나온 함수, f′(x)f'(x)f′(x), '에프 프라임'이라고 발음
  2. 미분계수 = 도함수의 변수 xxx에 상수를 넣은 결과,
    1. x=cx=cx=c일때 f′(c)f'(c)f′(c)
    2. x=1x = 1x=1일때 f′(1)f'(1)f′(1)
  3. 차수 : 미분을 몇 번했는가이다. f′(x)f'(x)f′(x) : 1차 미분방정식, f′′(x)f''(x)f′′(x) : 2차 미분방정식
    1. 또는 계수라고 한다. f′(x)f'(x)f′(x): 1계 미분방정식, f′′(x)f''(x)f′′(x) : 2계 미분방정식

영어

  1. derivative : 도함수
  2. derivative at a point 또는 differential coefficient : 미분 계수

1.2. 구조

  1. 입력 -> 시스템 -> 출력
    1. XXX-> HHH -> (Y=)HX(Y=)HX(Y=)HX
  2. [입력 xxx가 시스템에 들어가] [변환]하고 [출력 yyy가 나온다].
  3. 결론
    1. 3개 중 2개를 아는 상황 -> 나머지 하나를 구하는 것이 방정식을 연구하는 목적이자 공학이다.
    2. y=ax+by = ax + by=ax+b : 시스템이다.

시스템 용어

  1. 시스템
  2. 블랙박스
  3. 커널
  4. (시스템) 방정식
    1. 시스템(또는 방정식)만 알면 세상 모든 일을 알 수 있다. (미래이든 과거이든, 현재이든)

1.3. 방정식이란?

  1. 함수에서 출력이 결정된 상태
  2. 입력과 출력의 관계를 나타내는 것 : 함수
  3. 시스템

2. 공업 수학이란?

2.1. 문자, 심볼

알파벳과 그리스 로마 문자를 차용해서 사용 한다.

수학자들이 방정식을 연구하다보니, 수를 대신할 심볼(symbol)이 필요했는데, 이때 사용할 심볼이 당연히 문자를 심볼로 사용한다.
사용하는 문자

  1. 알파벳 26개
    1. 예: 변수를 x, 출력 변수를 y로 사용
  2. 그리스 로마 문자 : 심볼을 사용하는 경우가 많아지다 보니, 26개 알파벳으로는 부족하다. 그래서, 옛날에 쓰던 그리스 로마 문자를 사용한다.
    1. 예 : Δx\Delta xΔx
    2. 예 : Σixi\Sigma_{i} x_iΣi​xi​

3. 미분방정식이란?

도함수를 가지고 원함수를 구하는 것이 목적이다.

예: f′(x)x+c=0f'(x)x + c = 0f′(x)x+c=0에서 f(x)f(x)f(x) 를 구하는 것.

3.1. 미분 용어

독립변수 xxx에 (원)함수 f(x)f(x)f(x)를 미분한다.

  1. 원함수 : f(x)f(x)f(x)
  2. 도함수 : f′(x)f'(x)f′(x)
  3. 미분계수 : f′(x)∣x=c=f′(c)\displaystyle \left. f'(x) \right\vert_{x = c} = f'(c)f′(x)∣x=c​=f′(c)
  4. 순간변화율 : 미분의 다른 표현
  5. 최대/최소 : 미분을 사용하는 대표적인 예

미분계수 : f′(x)∣x=c=f′(c)\displaystyle f'(x) \vert_{x = c} = f'(c)f′(x)∣x=c​=f′(c)

4. 선형성이란?

선형성(linearity)은 입력값의 변화에 비례하여 출력값이 일직선(linear)으로 변하는 성질을 뜻합니다.
수학/공학에서 합(가산성)과 상수배(동차성)가 성립하는 중첩의 원리(superposition)를 만족하는 특성으로, 복잡한 비선형 시스템과 달리 결과 예측이 가능한 단순한 1차 관계를 말합니다.

선형성의 핵심 조건(중첩의 원리)

  1. 가산성 : f(x+y)=f(x)+f(y)f(x+y) = f(x) + f(y)f(x+y)=f(x)+f(y) : 두 입력을 더한 후 함수 적용 = 각각 적용 후 합
  2. 동차성 : f(ax)=af(x)f(ax) = af(x)f(ax)=af(x) : 상수배를 한 후 함수 적용 = 함수 적용 후 상부배

선형성의 동의어 및 관련 표현

  1. 선형적(Linear): 직선 형태의 비례적인
  2. 1차(First-order) : 변수의 차수가 1인
  3. 비례 관계(Proportional) : 일정한 비율로 증가/감소하는
