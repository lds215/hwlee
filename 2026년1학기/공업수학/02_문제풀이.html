2.1. 19번 문제

지수적 증가. 만약 어떤 시간 ttt에서 박테리아의 증가율이 ttt에 존재하는 개체의 수에 비례하고 1주일에 두 배가 된다면, 2주 후에는 얼마나 많은 박테리아가 예상되는가? 4주 후에는?

문제 헤석

  • 조건: 만약 어떤 시간 ttt 에서 박테리아의 증가율 (y′(t)y'(t)y′(t))이 ttt 에 존재하는 개체의 수 (y(t)y(t)y(t)) 에 비례 (y′=ay)y' = ay)y′=ay)하고 1주일에 두 배가 된다면 (y(1)=2y(0)y(1) = 2y(0)y(1)=2y(0)),
  • 문제: 2주 후에는 얼마나 많은 박테리아가 예상되는가? 4주 후에는?

풀이

박테리아의 증가율이 현재 박테리아의 양에 비례하므로 시간 ttt에서의 박테리아의 양을 yyy라 하면,
y′=kyy' = kyy′=ky이다. 따라서 y=cekty = ce^{kt}y=cekt이다.
조건에서 y(1)=2y(0)y(1) = 2y(0)y(1)=2y(0)이므로 cek=2cce^k = 2ccek=2c이다.
k=ln⁡2k = \ln 2k=ln2
y=cetln⁡2y = ce^{t\ln 2}y=cetln2이다.
y(2)=ce2ln⁡2=4c=4y(0)y(2) = ce^{2\ln 2} = 4c = 4y(0)y(2)=ce2ln2=4c=4y(0)이고
y(4)=ce4ln⁡2=16c=16y(0)y(4) = ce^{4\ln 2} = 16c = 16y(0)y(4)=ce4ln2=16c=16y(0)이므로
∴\therefore∴ 2주 후는 4배, 4주 후에는 16배이다.
